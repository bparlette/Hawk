Make Claude finish the job without babysitting

Three steps. Total setup: about 6 minutes. After that, walk away.

Step 1 — One-time setup (5 min)

Open Claude Code in your project folder and paste this as your first message. Put your goal statement where indicated:

=== MY GOAL (do not change this) ===
<your goal statement goes here>

=== OPERATING RULES (how to pursue the goal above without me babysitting you) ===
1. PROGRESS.md is your memory. Create it in the project root now. After every step, append: timestamp, what you did, what happened, test results, and the single next step. On every start — including after any resume or restart — read PROGRESS.md first and pick up exactly where you left off. Never redo verified work.
2. Do not stop to ask me questions. Make your best technical call and keep moving. The ONLY acceptable reason to stop is a hard blocker (a file you can't access, a tool that won't run). If blocked, write "BLOCKED: <exactly what you need>" at the top of PROGRESS.md and stop.
3. Work in small loops: diagnose → change ONE thing → test → log. Finish one piece completely before starting the next.
4. If your context gets long, write a compact summary into PROGRESS.md before continuing.
5. Before fixing, write down what "done" means as checkable boxes in PROGRESS.md. Test each one yourself. Claim done only when every box passes.

START: If PROGRESS.md already exists, read it and continue. If not, spend ~30 minutes diagnosing first: reproduce the current broken behavior and document EXACTLY what is wrong in PROGRESS.md. Do not fix anything until the diagnosis is written down. Then fix the highest-impact issue first.
FINISH: When the goal is fully met, write "DONE" at the top of PROGRESS.md with a summary of what was wrong and what you changed.
ON RESUME: Do not ask what to do — read PROGRESS.md and continue.

Let it run until it creates PROGRESS.md and finishes the diagnosis. Then close it.

Step 2 — Start the loop (1 min)

Paste this into your terminal, in the project folder, and hit enter:

while true; do
  grep -q "^DONE" PROGRESS.md 2>/dev/null && { echo "Finished!"; break; }
  grep -q "^BLOCKED" PROGRESS.md 2>/dev/null && { echo "Claude is blocked — read PROGRESS.md"; break; }
  claude --dangerously-skip-permissions -p "Read PROGRESS.md and continue. Stop only when DONE or BLOCKED."
  sleep 30
done

Step 3 — Walk away

The loop re-runs Claude automatically every time it stops — your resume button, pressed for you. Each run reads PROGRESS.md, does one chunk of work, saves, and exits. It stops itself when it prints Finished! or blocked.

If it says blocked

Open PROGRESS.md, read the BLOCKED line at the top, fix whatever it needs (a file, a tool, a decision), delete the BLOCKED line, and re-run the loop from Step 2.
