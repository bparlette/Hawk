1 · Project overview

Toad City Baltimore is an open-world, cel-shaded street brawler set on Baltimore's Inner Harbor, built for phones first. You play Harold, an elderly toad with a cane. His wife Mavis (grey afro, floral dress, a handbag she swings) fights beside you under AI control. Together you clear crime out of each district around the harbour. Each landmark district has a set-piece fight and a boss, and the final boss is Mister Formstone. The real map is compressed about 3×: landmarks sit about one block apart, with a 6 m brick promenade along the water and land about two blocks deep. Day turns to night every 5 minutes (a 600 s loop), and at night the windows, street lamps and neon light up.

Tech stack

  • three.js r160 with plain ES modules. The game source is a set of src/*.js files that a shell script concatenates into one module (game.js). There is no bundler and no framework.
  • Everything procedural: geometry comes from three.js primitives in code, and every texture is drawn on a <canvas> at load. There are no image, model or font files to license. Audio is separate (not part of this work).
  • Look: MeshLambert plus a 3-band toon ramp injected with onBeforeCompile, vertex colours, inverted-hull ink outlines and PCF soft shadows from one sun. A ?retro=1 32-bit mode exists, but the kit is HD-only and that is what you deliver for.
  • How deliveries plug in: each module is a file that receives the kit object K (the same functions the game uses). In-house, we strip the export keywords, append the file to src/, bind K to the game's globals and register the build function in the gang, boss, prop or vehicle tables. If your module runs in the kit viewer, it runs in the game.

Target devices and performance budgets

The main target is an iPhone in portrait, 390×844 CSS px at DPR 2 (the game view is the tall area above the arcade panel), plus desktop Chrome and Safari. Aim for 60 fps, with a 30 fps floor on a mid-range iPhone. Current city frames measure 76–168 draw calls and 99k–346k triangles at five spots (day, 390×844, including the shadow pass), so new assets must be lean.

Use mid-value base colours, because the toon ramp multiplies them by 0.46, 0.78 or 1.06. Never use pure #000 or #fff: use INK #14101f for black and at most #f2f2f2 for white. Shadows are tinted slightly cool.

Toon ramp (cel bands)

  • The lighting ratio r (lit luminance ÷ base luminance) is snapped to three bands: shadow 0.46 (r below 0.38–0.44), mid 0.78 and lit 1.06 (r above 0.86–0.92). Edges are hard (smoothstep over 0.06).
  • The shadow band is tinted by (0.88, 0.86, 1.10) at 50%. Strong local light (r above 1.35, such as a lamp at night) passes through unbanded.
  • A hit-flash uniform mixes the whole rig to white (mat.userData.flash). Every sub-material of a rig must share it.

Ink outlines

  • The outlines are inverted hulls: back faces of the same geometry pushed out along a mitred vertex direction (odir, from addOdir()), coloured INK #14101f.
  • Width = uW × camera distance, with the distance clamped to 2.5–36 m. Characters 0.0042, city 0.0034, props 0.0030. That gives a near-constant 2–3 px line on a phone, which fades into the fog colour with distance.
  • Only major masses get hulls. Use outline: false on parts thinner than about 4 cm (characters) or 6 cm (buildings), and on flat decals. Never use screen-space edge detection.

  • Street lamps are warm orange #ffa050: additive glow pools on the ground, billboard halos, and 4 pooled point lights (intensity 16, range 15 m) that follow the hero. Assets never add their own lights; they register lamp points instead.
  • A cool camera-side fill (#c8d0ff, 3.2) keeps characters readable at night. Do not make character bodies emissive; only intentional glow parts (a ghost, crystals, sparks) may glow.

3 · Code starter and interface

Every delivery is a drop-in JS module: no imports, one META, build functions that take K. Below is a real excerpt from the game, the opening of the thug builder exactly as it ships, followed by the kit examples that define the interface you must follow.

Real excerpt: how the game builds a thug (src/04_actors.js)

function buildThug(look) {
  const mat = toonMat(); const d = THUG_D, J = skeleton(d, mat);
  const { jacket, pants, skin } = look;
  part(J.hips, G.sph(0.22, 0.15, 0.17), pants, 0, 0.02, 0);
  part(J.hips, G.cyl(0.235, 0.235, 0.07, 14), '#14101f', 0, 0.1, 0, { outline: false });
  part(J.torso, G.sph(look.big ? 0.33 : 0.27, 0.33, look.big ? 0.24 : 0.2), jacket, 0, 0.3, 0);
  if (!look.big) { part(J.torso, G.box(0.09, 0.5, 0.03), '#14101f', 0.0, 0.3, 0.195, { outline: false }); part(J.torso, G.cyl(0.16, 0.2, 0.12, 12), jacket, 0, 0.6, 0); }
  else { part(J.torso, G.cyl(0.03, 0.03, 0.5, 6), '#ffd23c', 0, 0.48, 0.2, { rot: [Math.PI / 2 - 0.3, 0, Math.PI / 2], outline: false }); }
  const head = J.head = grp(J.neck, 0, 0, 0); head.userData.mat = mat;
  part(head, G.cyl(0.08, 0.09, 0.12, 10), skin, 0, 0.03, 0);
  part(head, G.sph(0.17, 0.2, 0.18), skin, 0, 0.2, 0.01);

The pattern: one toonMat per rig → skeleton(d, mat) → part(joint, G.prim(…), colour, x, y, z, opts) on each joint → J.head group under J.neck → J.kind → return J. The game wraps J in a Fighter (position, yaw, HP, AI), drives the joints with the pose tables and flashes J.mat on hits.

Prop interface: example_bench.js (complete)

// example_bench.js — the SHAPE every delivered static prop / kit piece must follow.
// No imports. Write placed world-space geometry into `out`; the game merges it into its chunk meshes (3 draw calls per chunk total).
export const META = { id: 'bench_slat', kind: 'prop', footprint: [1.8, 0.6], height: 0.9 };

export function buildBench(K, out, x, z, ang = 0, opts = {}) {
  const { THREE, place } = K, wood = opts.wood || '#9a6a44', iron = opts.iron || '#2c322e';
  const P = (g, lx, ly, lz) => { g.translate(lx, ly, lz); return place(g, x, 0.16, z, ang); }; // 0.16 = kerb / pavement height
  for (const [ly, lz, rx] of [[0.45, 0.0, 0], [0.45, 0.12, 0], [0.45, -0.12, 0]]) out.solid(P(new THREE.BoxGeometry(1.8, 0.05, 0.1), 0, ly, lz), wood);
  for (const ly of [0.62, 0.78]) out.solid(P(new THREE.BoxGeometry(1.8, 0.1, 0.05), 0, ly, -0.22), wood);
  for (const s of [-1, 1]) { out.solid(P(new THREE.BoxGeometry(0.06, 0.45, 0.42), s * 0.8, 0.22, 0), iron); out.solid(P(new THREE.BoxGeometry(0.06, 0.45, 0.05), s * 0.8, 0.7, -0.22), iron); }
  // a painted back-plate via the kit atlas (draw it once per module, reuse it for every instance)
  const atlas = buildBench.atlas || (buildBench.atlas = K.makeAtlas({ plate: { w: 256, h: 64, draw(c, w, h) { c.fillStyle = '#2f5a3a'; c.fillRect(0, 0, w, h);
    c.strokeStyle = '#f2e6c8'; c.lineWidth = 4; c.strokeRect(6, 6, w - 12, h - 12); c.fillStyle = '#f2e6c8'; c.font = 'bold 30px Georgia, serif'; c.textAlign = 'center'; c.fillText('HARBOR PARK', w / 2, 43); } } }));
  out.decal(P(new THREE.PlaneGeometry(0.9, 0.2), 0, 0.7, -0.19), atlas, 'plate');
  out.coll({ x, z, r: 0.7 });
  return META;
}

Rules that make code drop in

  • No import. No globals, no window, no DOM except canvas drawing inside texture or atlas functions. No Math.random() at build time (use a seeded LCG from opts.seed).
  • Characters return the rig J (bosses also export POSES and ATTACKS). Static pieces write only through out. Vehicles return { root, kind, seats, collider, waterline, animate }.
  • Facing is +Z, the base sits at y = 0 and units are metres. Materials come only from K. Never change toadcity_kit.js.

Task A: Baltimore rowhouse and city-block kit

Goal

Build a modular kit that fills the generic 24 × 24 m city blocks around the harbour with recognisably Baltimore rowhouse streets. The kit covers Formstone fronts, white marble stoops, bracketed cornices, painted window screens, corner bars and corner shops, in 3- and 4-storey variants. It must merge into the game's chunk meshes, so the whole city stays at a few draw calls per 64 m chunk.

Pieces to build

  1. buildRowhouse(K, out, atlas, x, z, ang, opts): one house. Frontage 4.2–6.0 m (2 or 3 window bays), depth 12–14 m, 3 or 4 storeys (opts.floors). Front facade options in opts.front:
  2. formstone: faux-stone cement facing in irregular blocks, grey-beige to pink-grey, drawn on the kit atlas.
  3. brick: red or tan brick, with optional painted brick (opts.paint).

  4. permastone: a smoother variant of Formstone. The house also has:

  5. A white marble stoop: 3–5 steps, 1.3–1.5 m wide, projecting 1.4–1.8 m onto the pavement, with a slight bevel. Use near-white #eae6dc with a cool shadow band.

  6. A cornice: a bracketed metal or wood cornice at the roofline, with 0.5–0.8 m projection, 4–8 brackets and a dentil band. Painted cornice colours come from the palette.
  7. Windows: 1/1 sash with lintels and sills; some ground-floor windows get painted window screens, which are original folk-art scenes drawn on canvas (a red-roof cottage by a lake, a swan, a lighthouse, a sailboat). Use at least 4 designs and no copies of real artworks.
  8. The door with transom and number, a basement window grille, a downspout, and a flat roof with a low parapet, a hatch and an optional rooftop deck.
  9. buildCornerBar(K, out, atlas, x, z, ang, opts): the end-of-row corner building with a chamfered corner door, a neon or painted sign: real Baltimore corner-bar styles are welcome (Natty Boh-style beer signs, "TAVERN", "CRAB HOUSE", "BAR & GRILL"), drawn on canvas, glass-block windows and an awning. The neon glows at night through out.glow().
  10. buildCornerShop(K, out, atlas, x, z, ang, opts): a corner store with a big front window, a roll-up security shutter (half-open option) and a sign ("CORNER MARKET", "CARRYOUT", "BARBER", "HARDWARE", "LAUNDROMAT", "DELI"), plus real local product signs in the window (Utz, Old Bay, Natty Boh-style), drawn on canvas.
  11. buildRowBlock(K, out, atlas, x0, z0, x1, z1, opts): fills one block. Houses face all four streets and stand shoulder to shoulder, with a corner bar or shop on 1–2 corners and a 3 m rear alley or yard strip in the middle (out.coll closes it). It mixes fronts, heights, colours and stoops from opts.seed. Neighbours never repeat the same front and colour.
  12. KIT_TILES: the canvas-drawn tiles (Formstone, brick, painted screens, signs, door and window details) for one 1024² atlas, made with K.makeAtlas(KIT_TILES).

import * as THREE from 'three';

const TAU = Math.PI * 2;
const clamp = (v, a, b) => (v < a ? a : v > b ? b : v);
const lerp = (a, b, t) => a + (b - a) * t;
const damp = (a, b, r, dt) => a + (b - a) * (1 - Math.exp(-r * dt));
const wrapA = (a) => { a = (a + Math.PI) % TAU; if (a < 0) a += TAU; return a - Math.PI; };
const ease = (t) => t * t * (3 - 2 * t);

// ---- toon (cel) material: MeshLambert + vertex colours + 3 hard bands + a hit-flash uniform ----
function toonMat(opts = {}) {
  const m = new THREE.MeshLambertMaterial(Object.assign({ vertexColors: true }, opts));
  m.userData.flash = { value: 0 }; m.userData.flashC = { value: new THREE.Color(1, 1, 1) };
  m.onBeforeCompile = (sh) => {
    sh.uniforms.uFlash = m.userData.flash; sh.uniforms.uFlashC = m.userData.flashC;
    sh.fragmentShader = sh.fragmentShader
      .replace('#include <common>', '#include <common>\nuniform float uFlash; uniform vec3 uFlashC;')
      .replace('#include <opaque_fragment>', `
        { // HD cel bands: shadow 0.46 / mid 0.78 / lit 1.06 of the base colour, hard edges; shadows tinted cool
          float ld = max(dot(diffuseColor.rgb, vec3(0.299, 0.587, 0.114)), 1e-3), lo = dot(outgoingLight, vec3(0.299, 0.587, 0.114)), r = lo / ld;
          float b = mix(0.46, 0.78, smoothstep(0.38, 0.44, r)); b = mix(b, 1.06, smoothstep(0.86, 0.92, r)); b = mix(b, r, step(1.35, r));
          outgoingLight *= b / max(r, 1e-3);
          outgoingLight = mix(outgoingLight, outgoingLight * vec3(0.88, 0.86, 1.1), (1.0 - smoothstep(0.38, 0.44, r)) * 0.5); }
        outgoingLight = mix(outgoingLight, uFlashC, uFlash);
        #include <opaque_fragment>`);
  };
  m.customProgramCacheKey = () => 'psx' + (opts.map ? 'M' : '');
  return m;
}

const OUT_U = { fogC: { value: new THREE.Color('#000') }, fogN: { value: 100 }, fogF: { value: 200 } };
function outlineMat(w) {
  return new THREE.ShaderMaterial({
    uniforms: { uW: { value: w }, uC: { value: new THREE.Color(INK) }, uFogC: OUT_U.fogC, uFogN: OUT_U.fogN, uFogF: OUT_U.fogF },
    vertexShader: `attribute vec3 odir; uniform float uW; varying float vD;
      void main() { vec4 wp = modelMatrix * vec4(position, 1.0); vec3 wd = mat3(modelMatrix) * odir;
        float d = distance(wp.xyz, cameraPosition); wp.xyz += wd * uW * clamp(d, 2.5, 36.0);
        vD = d; gl_Position = projectionMatrix * viewMatrix * wp; }`,
    fragmentShader: `uniform vec3 uC; uniform vec3 uFogC; uniform float uFogN; uniform float uFogF; varying float vD;
      void main() { gl_FragColor = vec4(mix(uC, uFogC, smoothstep(uFogN, uFogF, vD)), 1.0);
        #include <colorspace_fragment>

}

function addOdir(g) {
  const p = g.attributes.position, n = g.attributes.normal, map = new Map(), keys = [];
  for (let i = 0; i < p.count; i++) {
    const k = Math.round(p.getX(i) * 1e3) + ',' + Math.round(p.getY(i) * 1e3) + ',' + Math.round(p.getZ(i) * 1e3);
    keys.push(k); let e = map.get(k); if (!e) map.set(k, (e = []));
    const nx = n.getX(i), ny = n.getY(i), nz = n.getZ(i);
    if (!e.some((q) => q[0] * nx + q[1] * ny + q[2] * nz > 0.985)) e.push([nx, ny, nz]);
  }
  const res = new Map();
  for (const [k, e] of map) {
    let x = 0, y = 0, z = 0; for (const q of e) { x += q[0]; y += q[1]; z += q[2]; }
    const l = Math.hypot(x, y, z) || 1; x /= l; y /= l; z /= l;
    let mn = 1; for (const q of e) mn = Math.min(mn, q[0] * x + q[1] * y + q[2] * z);
    const s = 1 / Math.max(mn, 0.35); res.set(k, [x * s, y * s, z * s]);
  }
  const o = new Float32Array(p.count * 3);
  for (let i = 0; i < p.count; i++) { const d = res.get(keys[i]); o[i * 3] = d[0]; o[i * 3 + 1] = d[1]; o[i * 3 + 2] = d[2]; }

  return g;
}

  for (const g of list) { const c = g.attributes.position.count; P.set(g.attributes.position.array, o * 3); N.set(g.attributes.normal.array, o * 3); C.set(g.attributes.color.array, o * 3); if (U) U.set(g.attributes.uv.array, o * 2); o += c; }
  const m = new THREE.BufferGeometry(); m.setAttribute('position', new THREE.BufferAttribute(P, 3)); m.setAttribute('normal', new THREE.BufferAttribute(N, 3)); m.setAttribute('color', new THREE.BufferAttribute(C, 3));
  if (U) m.setAttribute('uv', new THREE.BufferAttribute(U, 2));
  m.computeBoundingSphere(); return m;
}
const CITY_MAT = toonMat();                                   // ONE shared material for every static kit piece
const GLOW_MAT = new THREE.MeshBasicMaterial({ vertexColors: true, transparent: true, opacity: 0 });
// makeAtlas(): every texture a kit needs is DRAWN on canvas at load (no image files) and packed into ONE 1024x1024 atlas
//   tiles = { name: { w, h, draw(ctx, w, h) } }   (w, h in px; keep the total under 1024x1024)
function makeAtlas(tiles, size = 1024) {
  const c = document.createElement('canvas'); c.width = c.height = size; const x = c.getContext('2d'), R = {}; let ax = 0, ay = 0, row = 0;
  for (const [name, t] of Object.entries(tiles)) {
    if (ax + t.w > size) { ax = 0; ay += row; row = 0; } if (ay + t.h > size) throw new Error('atlas full at ' + name);
    x.save(); x.translate(ax, ay); x.beginPath(); x.rect(0, 0, t.w, t.h); x.clip(); t.draw(x, t.w, t.h); x.restore();
    R[name] = [(ax + 1) / size, 1 - (ay + t.h - 1) / size, (t.w - 2) / size, (t.h - 2) / size]; ax += t.w; row = Math.max(row, t.h);
  }
  const tex = lowTex(c); const mat = toonMat({ map: tex, alphaTest: 0.5, side: THREE.DoubleSide });
  return { canvas: c, tex, mat, rect: (n) => R[n] };
}
function makeOut() {
  const S = [], OL = [], GL = [], DC = new Map(), out = { COLL: [], BLD: [], LAMPS: [], HOOKS: {} };
  const flat = (g) => (g.index ? g.toNonIndexed() : g);
  out.solid = (g, col, outline = true) => { g = flat(g); bakeColor(g, col); if (g.attributes.uv) g.deleteAttribute('uv'); S.push(g); if (outline) OL.push(g); };
  out.glow = (g, col) => { g = flat(g); bakeColor(g, col); if (g.attributes.uv) g.deleteAttribute('uv'); GL.push(g); };
  out.decal = (g, atlas, name) => { g = flat(g); const r = atlas.rect(name), uv = g.attributes.uv; if (!r) throw new Error('no tile ' + name);
    for (let i = 0; i < uv.count; i++) uv.setXY(i, r[0] + uv.getX(i) * r[2], r[1] + uv.getY(i) * r[3]);
    bakeColor(g, '#ffffff'); (DC.get(atlas) || DC.set(atlas, []).get(atlas)).push(g); };
  out.coll = (c) => out.COLL.push(c); out.bld = (b) => out.BLD.push(b); out.lamp = (x, y, z) => out.LAMPS.push({ x, y, z });
  out.hook = (type, data) => (out.HOOKS[type] || (out.HOOKS[type] = [])).push(data);
  // build(): 1 toon mesh + 1 outline hull + 1 glow mesh = 3 draw calls for everything written so far
  out.build = () => {
    const grp = new THREE.Group();
    if (S.length) { const m = new THREE.Mesh(mergeGeoms(S), CITY_MAT); m.castShadow = m.receiveShadow = true; grp.add(m); }
    if (OL.length) { const g = addOdir(mergeGeoms(OL)); const h = new THREE.Mesh(g, OUT_CITY); grp.add(h); QUAL.outlines.push(h); }
    if (GL.length) { const m = new THREE.Mesh(mergeGeoms(GL), GLOW_MAT); m.renderOrder = 2; grp.add(m); }
    for (const [atlas, list] of DC) { const m = new THREE.Mesh(mergeGeoms(list, true), atlas.mat); m.castShadow = m.receiveShadow = true; grp.add(m); } // +1 call per atlas
    return grp;
  };
  return out;
}
