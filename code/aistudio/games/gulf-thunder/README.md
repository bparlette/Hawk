# Gulf Thunder

Original 16-bit action game for tall portrait phone screens (270x480 logical, integer-scaled, backdrop extended to fill the screen).
Live: https://gulf-thunder.surge.sh

Five stages: Gulf Run (vertical boat shooter), Paradise Beach (belt brawler), Mangrove Chase (boat + jet-ski + stealth cloak),
Kasbah Rooftops (vertical climb shootout), Stunt Backlot (brawl/shootout vs. a taxiing prop plane).

Controls: floating stick + FIRE / JUMP-BOOST / SPECIAL on touch; WASD/arrows + J / K / L on keyboard; gamepad (X fire, A jump, B special).
Test flags: `?stage=N` start at stage N, `?god` invincible, `?bot` autoplay, `?speed=N` fast-forward, `?mute`.
All art is drawn procedurally in code (js/art.js and the stage files); no image assets.
