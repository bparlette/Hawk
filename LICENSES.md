# Licences

All original, procedural. Every mesh is built from three.js primitives in code and the one texture (the fur map) is drawn
on a canvas at load. No image, model or font files, no third-party code in `src/`, no traced artwork, no real people,
mascots, brands or real gang colours/symbols.

- three.js r160 (MIT, https://github.com/mrdoob/three.js/blob/r160/LICENSE) — loaded by `viewer.html` from unpkg only; not copied into this delivery.
- `toadcity_kit.js` / `example_gull_thug.js` — Toad City Baltimore's own kit, rebuilt from the brief's appendix (see README "Kit note").
- `tools/shoot.mjs` uses playwright-core (Apache-2.0) as a dev tool; not part of the game.
