1. Token & Cost Economics

Running the 7B model locally on your Apple Silicon Mac saved 100% of API token costs (\$0.00 vs \$0.018 for Frontier generation).

  • Local 7B: 1,874 total tokens consumed locally with zero cloud footprint.
  • Inference Speed: Frontier cloud runs at ~180-210 tok/s (~12-18s per full game), whereas local 7B generates at ~5.3-5.7 tok/s (~1.5-2.8 minutes per game).
  • Best ROI Pattern: Use Local 7B for repetitive drafting, localization, and mechanical scripts; use Frontier for complex 60fps physics, particle engines, and custom SDK architectures.

2. The Gamepress SDK Effect

Gamepress acts as a 3x token compressor and quality multiplier for web games.

  • Without Gamepress (Vanilla): Both models had to write their own canvas loops, event handling, math clamps, collision boundaries, and audio routines (up to 435 lines).
  • With Gamepress: Gamepress provides built-in `createGame`, automatic touch/keyboard bindings, screen shake (`hitstop`), particle emitters (`burst`), and synthesized audio (`sfx`, `comboPitch`), cutting code complexity dramatically.
  • 7B SDK Adaptation: Smaller models require explicit in-context schema snippets to prevent hallucinating Phaser/generic API patterns.

3. Physics & Polish Nuances

The difference in gameplay feel between the Frontier and 7B models comes down to three mathematical details:

  • Tilt Rotation: Frontier models apply smooth velocity lerping (`bird.rot += (targetRot - bird.rot) * 0.22`), giving authentic Balatro/Flappy feel; 7B used static unrotated circles.
  • Procedural Audio: Frontier wrote zero-dependency Web Audio synthesizers (whoosh, chime, thud); 7B linked an external MP3 URL that can fail on CORS/offline.
  • State Cleanup: Frontier properly cancels requestAnimationFrame loops on game over to avoid frame accumulation bugs upon restart.
